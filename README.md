# ATM App

This is a simple ATM simulation app that allows users to withdraw cash in $20 and $50 notes.

## How to run
- Open `index.html` directly in a browser, or
- Visit the live site: https://sjhnz123.github.io/Code-Challenge/
  
## How it works
- The ATM is initialized with a set number of $20 and $50 notes.
- When a withdrawal or deposit is requested, the app tries to dispense using available notes.
- If no legal combination is possible, an error is shown.

## Thought Process
- Combination search is used instead of $50 first to avoid combination issues.
- The ATM preserves available notes where possible.
